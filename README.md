# حافلاتي — Hawafilati

نسخة MVP تجريبية عربية لنظام إدارة النقل المدرسي في مدرسة أبو القاسم الزهراوي للتعليم الأساسي (5–9).

## ما تتضمنه النسخة

- لوحة تشغيل وإحصاءات للحافلات والطلاب.
- 824 طالبًا تجريبيًا موزعين وفق أعداد الصفوف والشعب الفعلية.
- 10 حافلات حكومية بسعاتها الحالية.
- النقل الحكومي، النقل الخاص، المشي، وغير محدد.
- بوابة تجريبية لولي الأمر باستخدام `STU0001` إلى `STU0824`.
- واجهة سائق أولية لمشاركة الموقع والرابط عبر واتساب.
- إعادة ضبط البيانات التجريبية.
- واجهة عربية RTL ومتجاوبة.

## التشغيل المحلي

افتح `index.html` مباشرة، أو شغّل خادم ملفات محليًا. الموقع لا يحتاج إلى بناء أو تثبيت حزم.

## النشر على GitHub Pages

1. ارفع محتويات المشروع إلى مستودع GitHub.
2. افتح Settings ثم Pages.
3. اختر النشر من فرع `main` والمجلد `/root`.

> هذه نسخة عرض فقط. المصادقة الحقيقية، حفظ البيانات، التتبع المستمر في الخلفية، والصلاحيات تحتاج خادمًا خاصًا وتطبيق سائق مناسبًا. لا تضع بيانات الطلاب الحقيقية في مستودع عام.

## بيانات المدرسة المستخدمة

- 824 طالبًا، 22 شعبة، من الصف الخامس إلى التاسع.
- 10 حافلات حكومية بإجمالي 494 مقعدًا.
- 13 منطقة سكنية.

## خارطة الطريق

- API سحابي وصلاحيات RBAC.
- تخزين خاص ومشفّر للبيانات.
- اعتماد نقاط التوقف وطلبات أولياء الأمور.
- تطبيق سائق يدعم الموقع عند قفل الشاشة.
- روابط تتبع مؤقتة وسجل تدقيق.
- اختبارات وGitHub Actions.

## الخصوصية

جميع أسماء الطلاب وأرقامهم في هذه النسخة وهمية. لا يحتوي المشروع على بيانات طلاب حقيقية أو مفاتيح خدمات.
